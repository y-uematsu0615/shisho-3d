# 支承・伸縮装置 3Dモデル集

支承・伸縮装置の3Dビューア（ブラウザで動く単体HTML）。公開URL: https://y-uematsu0615.github.io/shisho-3d/

- `index.html` 入口ページ（「全モデルをオフライン保存」ボタン付き）
- 実寸図面モデル：`BPB-400M` `BPB-400F` `RB-500F` `RB-430M`（日本支承協会 標準設計図の寸法）
- 伸縮装置：`mageba`（マゲバ マルチタイプ）、`maurer-joint`（E-320）、`maurer-swivel`（ES-320）
- 構造図モデル（推定・保留中）：`S01` `S04`〜`S14` `S16`〜`S18`（支承構造・分解図の図番）
- `sw.js` `manifest.webmanifest` オフライン保存とホーム画面追加用
- `thumbs/` 入口ページのサムネイル

推定箇所は各ページの注記を参照。
